# RH Costa Rica - Nómina Avanzada

Complemento de `l10n_cr_hr` para procesos excepcionales de nómina.

## Incluye
- Retroactivos sin modificar recibos cerrados.
- Generación de incidencias para nómina complementaria.
- Trazabilidad del período de origen.
- Liquidación avanzada con referencia legal congelada y acuerdo negociado.
- Comparación referencia vs. acuerdo, evidencia y reversión controlada.

Todo el contenido visible al usuario está definido en español.

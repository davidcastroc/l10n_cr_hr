# RH Costa Rica - Ausencias y Eventos Tardíos

Complemento para registrar eventos recibidos después de que la operación original ya fue procesada.

## Incluye
- Incapacidad CCSS tardía.
- Incapacidad INS tardía.
- Maternidad y paternidad tardías.
- Documento obligatorio y número único por compañía.
- Identificación de ausencias superpuestas.
- Restitución de vacaciones al rechazar una vacación sustituida por incapacidad.
- Identificación de recibos cerrados afectados para tratamiento complementario sin reabrirlos.
- Cancelación controlada antes de aplicar el evento.

Todo el contenido visible al usuario está definido en español.
